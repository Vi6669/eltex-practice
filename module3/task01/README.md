Задание 1 (fork + файлы + каналы) 
Разработать программу, которая создает копии указанных файлов. 
Имена файлов передаются в списке аргументов запуска программы. 
Если файл с указанным именем не существует, выводится диагностическое 
сообщение в stderr. 
При запуске порождается дочерний процесс. Родительский процесс 
будет считывать содержимое файла, и передавать его дочернему процессу по 
каналу (pipe). Дочерний процесс записывает полученные фрагменты в 
новый файл (к имени добавляется .copy). По окончании передачи файла 
будет передаваться следующий файл, или оба процесса завершаются. 
Если в аргументах запуска указан параметр с ключом -p, он означает 
имя создаваемого канала. Если ключ -p отсутствует, используется 
неименованный канал. 
Для начала передачи дочерний процесс помещает в канал сообщение о 
готовности к приему данных (двухстороннее взаимодействие). 
В первом сообщении от родительского процесса содержится 
информация об имени файла и количестве передаваемых байтов. 
Содержимое файла передается блоками из нескольких байтов. 
Для работы с файлами использовать функции небуферизованного 
ввода-вывода (open, read, write, close). 
После передачи всех файлов родительский процесс уведомляет 
дочерний о завершении работы и ожидает, когда завершится дочерний 
процесс. 
Для запуска программы рекомендуется сделать скрипт, который 
тестирует работу при различных параметрах запуска (в том числе 
некорректных).
